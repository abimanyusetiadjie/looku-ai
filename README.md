# 🧥 LOOKU — Curated Daily OOTD & Personal Color Studio

> **"Formula gaya harian yang bernapas di iklim tropis & selaras dengan warna kulitmu."**  
> Asisten gaya harian berbasis AI pertama di Indonesia yang memadukan analisis **Personal Color (Undertone)**, iklim tropis, arsitektur modest/hijab native, serta terintegrasi langsung dengan link belanja Shopee & Tokopedia.

---

## 🌟 Fitur Utama Looku

1. **Personal Color & Skin Tone Matrix (5 Tipe Kulit Indonesia)**:
   - *Putih Gading (Fair)*, *Kuning Langsat (Light)*, *Sawo Matang (Medium)*, *Eksotis (Tan)*, *Deep Bronze*.
   - Menganalisis kecocokan palet baju agar kulit tampak cerah dan glowing.
2. **AI Fashion Studio Generator (P1)**:
   - Input ramah pengguna: Acara, Cuaca Tropis (32°C–35°C), Budget Shopee/Tokopedia, Toggle Modest/Hijab, Age Group (Teens, 20s, 30s, 40s+), dan Vibe.
3. **Trending Lookbook Feed Indonesia**:
   - Inspirasi gaya nyata harian (*Jakarta, Bandung, Bali, Surabaya*) dengan fitur 1-klik muat ke studio.
4. **Shopee & Tokopedia Affiliate Engine**:
   - 1-klik tombol pencarian produk serupa dengan referral tag otomatis.
5. **Instagram Stories / WhatsApp Status Exporter (9:16 Magazine Cover)**:
   - 1-klik unduh kartu editorial HD berlatar estetik lengkap dengan barcode kurasi dan palet warna.
6. **Mobile App-Shell Navigation**:
   - Bottom Tab Bar melayang di smartphone untuk pengalaman native app tanpa instalasi.

---

## 🚀 Cara Menjalankan Secara Lokal

1. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```
2. Buka browser di [http://localhost:3000](http://localhost:3000).

---

## ☁️ Panduan Deploy ke Vercel (Gratis Rp 0 / Bulan)

1. Upload repository ini ke akun **GitHub** kamu.
2. Buka [Vercel.com](https://vercel.com) dan login dengan GitHub.
3. Klik **"Add New Project"** dan import repo `Looku-AI`.
4. Klik **Deploy**! Website kamu akan langsung aktif dengan domain `https://looku.vercel.app`.
